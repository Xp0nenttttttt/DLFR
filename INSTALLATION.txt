# DLFR 2.7.1 — Correctif création de Level Packs

## Symptôme
Dans Modération > Level Packs, le bouton « Enregistrer le pack » affiche :
`column reference "id" is ambiguous`.

## Cause
La fonction `public.dlfr_save_level_pack` contenait une jointure avec
`unnest(p_level_ids) AS id` et `public.demons d` puis la condition
`d.id=id`. Deux colonnes `id` étaient visibles, donc PostgreSQL ne
pouvait pas résoudre la référence.

## Installation
1. Fais une sauvegarde de la base Supabase.
2. Ouvre Supabase > SQL Editor.
3. Exécute `supabase/41_CORRECTIF_CREATION_LEVEL_PACKS.sql`.
4. Retourne au panneau Level Packs, recharge, puis réessaie d'enregistrer.

Aucun fichier HTML/CSS/JS à remplacer. Il n'est pas nécessaire de réexécuter
la migration 40. Cette migration ne crée ni ne supprime de données.

## Vérification
Après exécution, la fonction est remplacée, les autres tables et données restent
inchangées. Si une autre erreur survient, copie son message complet pour
identifier le problème suivant ; elle ne peut être confirmée qu'avec la base réelle.
