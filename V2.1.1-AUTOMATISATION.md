# V2.1.1 — Retirer automatiquement les niveaux déjà battus

La feuille `data/niveaux-non-battus.xlsx` reste le catalogue AREDL. **Aucune modification de fichier Excel nécessaire.**

En mode données réelles (une fois les niveaux et les records importés dans Supabase), un niveau est retiré si :

1. « Vérifié communauté » = `Oui` dans l’Excel ; ou
2. Le même niveau (correspondance prioritaire via ID Geometry Dash) possède un vérificateur renseigné dans la Demonlist ; ou
3. La Demonlist contient une complétion à **100 %** de ce niveau.

Les entrées masquées sont consultables sous **« Voir les niveaux retirés »**, avec la raison du retrait et un lien vers la fiche Demonlist si elle existe. Un niveau simplement classé sur AREDL ou possédant un lien sans preuve n’est **pas** considéré comme battu par la communauté.

**Pendant la migration :** en mode `?demo=1`, le site ne confond pas les complétions fictives avec les véritables records français. Donc les exclusions automatiques ne seront disponibles qu’une fois les vraies données importées ; les lignes `Oui` dans l’Excel fonctionnent immédiatement.

## Installer

Remplacer `js/app.js`, `js/community-unverified.js` et `css/style.css` avec les fichiers du patch. Ne pas modifier `js/config.js`. Pas de SQL supplémentaire.

Recharger GitHub Pages avec Ctrl + F5.
