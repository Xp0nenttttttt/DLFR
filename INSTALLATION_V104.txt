INSTALLATION (sur la version V103 du site)
1. Remplacer index.html à la racine.
2. Remplacer js/app.js et js/production-tools.js.
3. Ne pas remplacer les autres scripts, CSS, drapeaux ou personnalisations.
4. Publier sur GitHub Pages puis forcer Ctrl+F5.

La base DLFR de production a déjà été mise à jour :
- niveau unique par (ID Geometry Dash, mode de complétion), au lieu d'ID seul ;
- champ requested_completion_mode ajouté à level_submissions ;
- contrôles anti-doublons des soumissions séparant les variantes Solo / 2P ;
- fonction de validation utilisant la variante explicite et réutilisant une fiche AREDL masquée du même mode.
Aucun SQL supplémentaire n'est nécessaire.
