DLFR V129 — DLFR Cards : mode Aventure pour tous
================================================

Base de données : DÉJÀ APPLIQUÉE (supabase/129_CARTES_AVENTURE.sql = archive).

1) Mode Aventure ouvert à tous (bouton « 🗺️ Mode Aventure » sur la page Cartes)
 - Tout le jeu du labo : boosters à éclats ◆, expéditions, niveaux et rangs,
   talents, Forge (étoiles, fabrication), quêtes, succès, renaissance.
 - Partie SAUVEGARDÉE automatiquement sur le compte (indicateur « ✓ Sauvegardé »).
   Si la même partie est ouverte dans deux onglets, le plus ancien s'arrête de
   sauvegarder et demande de recharger : aucune progression écrasée.
 - Ressources propres au mode Aventure (◆ ✧ 🔑) : il ne donne JAMAIS de
   Wayllings dorés. La collection officielle (booster du jour, doublons et
   collections → Wayllings) reste sur la page Cartes.
 - « Exporter ma partie » reste disponible pour tous.

2) Catalogue + outils de test : propriétaires ET supermodérateurs
 - Onglets « ✎ Catalogue », « Échanges fictifs », « Outils de test » visibles
   seulement pour eux (et lien « Catalogue DLFR Cards » dans leur menu compte).
 - Créer / modifier / supprimer cartes et collections : vérifié côté serveur
   (owner ou supermoderator).
 - Utiliser un outil de test (+1 carte, toutes les cartes, +◆…) ou importer une
   sauvegarde passe la session en « SESSION DE TEST · NON SAUVEGARDÉE » :
   la vraie partie du compte n'est pas modifiée.

Fichiers : index.html, js/app.js, js/v118-cards-lab.js, js/v127-cards.js,
           css/v127-economy.css, supabase/129_CARTES_AVENTURE.sql (archive)
