# DLFR V2.5 — Discord (démo + préparation OAuth)

Nouveau : `js/discord-auth.js`, carte Discord dans **Mon profil**, liaison de démonstration validée par un modérateur simulé, choix avatar personnalisé/Discord. Authentification Supabase prête à activer dans le futur.

**Il n'y a pas de connexion Discord active en mode démo**, ni de migration SQL, ni de changement des identifiants de modération. Les images dans `assets/flags/` ne sont **pas** livrées ; conservez vos PNG régionaux existants.

Pour l'installation, les procédures futures et les règles de sécurité, lire [DISCORD-V2.5-A-LIRE.md](DISCORD-V2.5-A-LIRE.md).
