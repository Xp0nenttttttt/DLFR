DLFR V148 — Alerte anti-doublon dans le Catalogue des cartes
============================================================
(Inclut V147 et avant. Aucune requête SQL.)

Onglet ✎ Catalogue (propriétaires / supermodos) :
 - En tapant le nom d'une carte, un bandeau rouge « ⚠ Existe déjà : « Zodiac » (#005 ·
   collection · rareté) » apparaît si une carte porte déjà ce nom (majuscules, accents,
   espaces et ponctuation ignorés), dans n'importe quelle collection.
 - Un nom proche (l'un contient l'autre) est signalé en orange.
 - À l'enregistrement d'une nouvelle carte (ou d'un renommage) avec un nom déjà pris :
   fenêtre de confirmation « Attention, doublon possible ! … Créer quand même ? ».
 - Import de cartes (JSON) : les cartes dont le nom existe déjà sont ignorées et listées
   dans la confirmation.

Fichiers : index.html, js/v118-cards-lab.js, css/v131-cards.css
