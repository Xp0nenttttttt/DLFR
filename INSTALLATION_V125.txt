DLFR V125 — Notifications Discord
==================================

Aucun bot à héberger : Supabase envoie lui-même les messages à Discord via des
« webhooks » (un par salon). La partie base de données est DÉJÀ INSTALLÉE sur DLFR.
Tant que les webhooks ne sont pas renseignés, rien n'est envoyé.

Ce que ça fait
 1. Salon modération : message dès qu'une soumission est envoyée (joueur, niveau,
    %, vidéo + miniature, raw footage, message du joueur, n° de demande).
    Option : mentionner un rôle (ex. @Modérateur).
 2. Salon joueurs : « ✅ acceptée » ou « ❌ refusée » quand une demande est traitée.
    Le joueur est @mentionné si son compte DLFR est lié à Discord (sinon son pseudo).
    Le message du modérateur n'est PAS affiché par défaut (option show_review_message).
 3. Salon actualités : chaque actualité publiée sur le site (titre, texte, image).
 4. Salon badges : quand la modération décerne un badge (ex. Goat de ta région),
    avec l'icône, la description et la couleur de rareté. Les badges automatiques
    ne sont pas annoncés (ça ferait trop de messages).

Mise en place (5 minutes)
 A. Dans Discord, pour CHAQUE salon : Modifier le salon → Intégrations → Webhooks
    → Nouveau webhook → Copier l'URL du webhook.
    (Tu peux utiliser le même salon pour plusieurs types si tu veux.)
 B. Pour mentionner un rôle : Paramètres → Avancés → Mode développeur, puis clic
    droit sur le rôle → Copier l'identifiant.
 C. Ouvre supabase/125_DISCORD_CONFIG_A_REMPLIR.sql, colle tes URL, puis exécute-le
    dans Supabase → SQL Editor. Il envoie un message de test dans chaque salon.
    Vérifie aussi site_url (adresse de ton site GitHub Pages).

⚠ Les URL de webhook sont secrètes (n'importe qui pourrait poster avec).
  Elles sont stockées dans une table illisible depuis le site.
  En cas de fuite : supprime le webhook dans Discord et recrée-le.

Couper temporairement : update public.dlfr_discord_config set enabled=false;

Fichiers : supabase/125_DISCORD_WEBHOOKS.sql (déjà appliqué, archive)
           supabase/125_DISCORD_CONFIG_A_REMPLIR.sql (à remplir et exécuter)
