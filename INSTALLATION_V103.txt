BASE : V102 messages joueurs / rangs UNRATED.

INSTALLATION GITHUB PAGES
  1. Remplacer index.html par celui de ce ZIP.
  2. Remplacer js/app.js par celui de ce ZIP.
  3. Publier / attendre la publication GitHub Pages, puis Ctrl + F5.

CORRECTIONS
  - L'onglet Équipe ne télécharge plus community_audit_log (plus de 38 000
    événements ; anciennement plus de 190 requêtes réseau de 200 lignes).
  - Une RPC agrégée ne retourne que les compteurs de fiches gérées par modo.
  - La liste des comptes et les compteurs arrivent en parallèle.
  - Le journal de modération ne charge que les 20 derniers événements.
  - Les autres fonctions, les rôles, les clans, les récompenses, le thème
    Halloween, les soumissions et les fichiers assets/flags restent intacts.
