# DLFR V2.4 — Mon profil + statistiques UNRATED

## Installer sur GitHub Pages

Partir de DLFR V2.3. Décompresser le **patch V2.4** dans la racine du dépôt, en conservant l'arborescence. Remplacer `index.html`, `css/style.css`, `js/app.js`, `js/demo-data.js` et **ajouter `js/unrated-stats.js`**. Conserver le fichier `js/config.js` de ton dépôt.

Attendre le déploiement GitHub Pages, recharger avec Ctrl+F5, puis ouvrir `?page=my-profile&demo=1`. Pour effacer la démonstration déjà enregistrée dans le navigateur, ajouter **une seule fois** `&reset=1` : cela efface la démo locale, pas Supabase.

## « Mon profil »

L'onglet apparaît dans la navigation. En démonstration, un sélecteur de joueur permet de tester les formulaires (biographie, avatar, bannière, liens, niveau favori, objectif, trois accomplissements, région française). Les modifications se reflètent sur les fiches « Statistiques » et sont stockées uniquement dans le navigateur. Pas besoin d'activer la modération.

Le pays, les points, les records, les titres, badges et sanctions ne sont **pas** modifiables par le propriétaire du profil.

**Sur un vrai site connecté à Supabase :** une connexion Supabase Auth seule ne suffit pas à autoriser un joueur à éditer une fiche. Il faut relier manuellement le compte connecté à une entrée `players`, après vérification, et installer les policies RLS. Tant que cela n'a pas été fait, « Mon profil » informe clairement l'utilisateur et reste en lecture seule. Un brouillon de migration est fourni dans `supabase/07_profil_joueur_PREPARATION_NE_PAS_EXECUTER.sql` et **ne doit pas être exécuté maintenant**. Le code n'autorise jamais un joueur à choisir librement l'identité du compte réel à modifier.

## Statistiques UNRATED

Dans « Statistiques », un nouvel onglet **UNRATED** présente les niveaux concernés, complétions à 100 %, vérifications et points simulés du classement alternatif. Le niveau fictif « **DÉMO — Eclipse Protocol (UNRATED)** » est intégré, placé au #28 **dans le classement alternatif**, avec une complétion fictive de Spleen.

Le classement officiel exclut les UNRATED. L'activation du bouton UNRATED recompose temporairement le Top 150 et son calcul de points, sans modifier les données Supabase. Les points UNRATED affichés séparément sont des simulations, pas des points officiels.

Les anciennes données de démo stockées localement reçoivent automatiquement le nouvel exemple sans supprimer les profils personnalisés.
