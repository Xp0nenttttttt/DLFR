# Installation V2.1

1. Sauvegarde le dépôt GitHub existant.
2. Remplace les fichiers du patch à leurs emplacements respectifs : `index.html`, `css/style.css`, `js/app.js`, `js/v2-demo.js`.
3. Ajoute le nouveau `js/clan-core.js` : vérifie que le nom est exactement celui-ci (majuscules/minuscules importantes sur GitHub Pages).
4. Fais un commit, puis visite `?demo=1&page=stats` et `?demo=1&page=clans`.
5. Pour tester l'invitation : joueur Spleen → clan Aurora ; joueur Illyes → Mes invitations.

Ne modifie ni la base SQL ni le fichier `js/config.js`.

Explications détaillées : [V2.1-CLANS-ET-STATS.md](V2.1-CLANS-ET-STATS.md).
