# DemonlistFrancophone V2.6 — navigation et palmarès

## Nouveautés

### Navigation allégée

Le menu principal contient désormais seulement **Demonlist** et trois menus déroulants :

- **Classements** : Statistiques des joueurs, Calculateur de points, Niveaux non vérifiés, Historique des records.
- **Communauté** : Clans, Actualités, Palmarès & exploits.
- **Mon espace** : Mon profil & Discord, Soumettre un record, Modération.

Les menus fonctionnent au clavier avec les éléments HTML natifs `details`/`summary`. Ils peuvent être fermés avec Échap ou par un clic ailleurs, et le menu actif est mis en évidence. Les réglages **Thème** et **UNRATED** restent accessibles dans l'en-tête.

### Hall of Fame et Achievements fusionnés

La nouvelle page **Palmarès & exploits** : `?page=honors`

Elle combine les données existantes :

- `hall_of_fame` pour les distinctions par année et catégorie.
- `fr_achievements` pour les runs et les exploits français.

Trois vues : **Tout voir**, **Distinctions**, **Exploits FR**. Les compteurs permettent de voir la quantité d'entrées de chaque type, ainsi que le nombre de joueurs mis en avant. Les liens vers les profils, les vidéos et les sources sont conservés. Le texte indique clairement que les exploits ne donnent pas de points.

Les anciennes URLs ne sont pas cassées :

- `?page=hall` : palmarès préfiltré sur les distinctions.
- `?page=achievements` : palmarès préfiltré sur les exploits.
- `?page=honors` : affichage réuni.
- `?page=honors&tab=hall` ou `&tab=achievements` : vues filtrées.

Les données demeurent dans leurs tables respectives, sans migration. Les formulaires de modération restent inchangés.

## Installer le patch sur GitHub Pages

1. Extraire l'archive de patch V2.6.
2. Remplacer **`index.html`**, **`js/app.js`** et **`css/style.css`** sur le dépôt GitHub.
3. Ne pas modifier `js/config.js` ni ton dossier personnalisé **`assets/flags/`**.
4. Vérifier le déploiement GitHub Pages, puis forcer le rafraîchissement (Ctrl + F5).
5. Tester avec `?page=honors&demo=1` (la démo demeure locale), puis tester les trois menus déroulants.

Pas de SQL ni de changement Supabase nécessaire pour cette mise à jour d'interface.

## Vérifications effectuées

- `node --check js/app.js` : OK.
- Tous les tests existants de V2.5 : OK (clans, UNRATED, soumissions, Discord, etc.).
- `node tests/navigation-palmares.test.js` : OK (navigation, regroupement des contenus, filtres, conservation des anciennes routes et publication).
- Rendu **statique** dans Chromium aux formats 1440 px et 390 px : aucun débordement horizontal, menus et cartes visibles.
- **Limite** : le navigateur de l'environnement de test bloque les URLs du serveur local (`ERR_BLOCKED_BY_ADMINISTRATOR`). Par conséquent, le chargement réel de l'application complète et toutes les interactions ne sont pas validés de bout en bout dans Chromium : il faut les confirmer après déploiement sur GitHub Pages.

## Protection des drapeaux

**Aucun fichier sous `assets/flags/` n'est inclus dans le patch ni dans l'archive complète.** La logique de drapeaux PNG régionaux à trois premières lettres existante est conservée telle quelle.
