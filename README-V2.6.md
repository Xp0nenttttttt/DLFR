Cette version simplifie l'interface : trois menus déroulants (Classements, Communauté, Mon espace), page commune **Palmarès & exploits** au lieu des deux entrées distinctes Hall of Fame / Achievements, compatibilité des anciennes URL, et affichage mobile réorganisé.

Pour l'installation et les tests, consulter **V2.6-NAVIGATION-PALMARES.md**.

**Aucun drapeau PNG fourni ou modifié.** Garder le dossier `assets/flags/` déjà présent dans le dépôt. Aucune migration SQL nécessaire pour les nouveautés visuelles.
