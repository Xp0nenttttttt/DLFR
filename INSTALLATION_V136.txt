DLFR V136 — Cartes du mode Aventure visibles dans la collection officielle
==========================================================================
 - Dans l'onglet « ★ Booster du jour », les cartes gagnées en mode Aventure
   s'affichent maintenant en couleur avec l'étiquette « 🗺️ Aventure »
   (au lieu de rester grises comme si elles manquaient).
 - Le compteur de chaque collection indique « + N cartes obtenues en Aventure ».
 - Seules les cartes officielles comptent pour les Wayllings (doublons recyclables,
   bonus de collection complète) : aucune triche possible via l'Aventure.
 - Le compteur ×N ne cache plus la pastille de rareté.
Aucune modification de la base de données.
Fichiers : index.html, js/v118-cards-lab.js, js/v127-cards.js, css/v131-cards.css
Le ZIP est cumulatif (V117 → V136) : copie tout à la racine du dépôt.
